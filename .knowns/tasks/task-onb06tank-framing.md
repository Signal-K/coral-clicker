# Reframe The Tank for first-time players

## Problem

The Tank currently reads like a utility or debug panel rather than a rewarding sandbox/hub.

Observed issues:
- very sparse presentation
- no strong explanation of why the player should care
- the screen exposes controls before establishing the fantasy or value of the space

## Why this is urgent

If the hub feels like admin UI, players will either ignore it or assume it is unfinished.

## Required outcome

- Introduce The Tank as a reward/management space, not a tools panel
- Explain why the player would visit it in game terms
- Improve visual presentation and first-visit framing

## Acceptance notes

- A first-time player should understand what The Tank is for within a few seconds
- The screen should feel like a playable part of the game, not backstage UI
