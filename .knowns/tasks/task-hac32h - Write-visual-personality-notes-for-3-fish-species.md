# Fill species visual reference grid — first 3 fish

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Fill in the species visual reference grid for the first 3 reef fish. The grid structure is pre-defined — fill each column, no freeform prose.

**Species:**
- Blue Chromis
- Parrotfish
- French Angelfish

**Columns per species:**

| Column | What goes here |
|---|---|
| Colour palette | 2–3 hex codes + one-word label (e.g. `#1A8FD1` electric-blue) |
| Movement type | One of: lazy-drift / darting / hovering / cruising / territorial-patrol / ambush |
| Swim zone | reef-surface / mid-water / open-water / bottom |
| Stress reaction | What they do when threatened (scatter, hide, freeze, display, school) |
| Interaction signature | The one visible thing they do in the reef (grazes coral, picks at sponge, patrols territory) |
| Animator brief | One line max — the thing the animator must nail |

Output: filled grid (table). That's it — no prose writeup.
