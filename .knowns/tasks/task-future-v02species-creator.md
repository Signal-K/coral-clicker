# REMINDER: Custom species faces/colours creator

**Do not implement until 2026-03-31 sprint.**

## What this is

When a player breeds a new species, they will eventually be able to **customise its appearance** from a defined mix-and-match list:
- Choose a face style from a set of predefined options
- Choose a colour palette from a set of predefined options
- "Mix and match" two-part approach (e.g. face A + colours B)

This is a cosmetic layer on top of the new species naming system (which is in scope now — see task-gp09traits).

## v0.1 scope boundary

For now: player **names** the new species only. Face/colour is auto-assigned (use parent species art as a base or a default fallback).

## When this triggers

Design session needed to:
1. Define the set of available face styles
2. Define the set of available colour palettes
3. Build the mix-and-match UI (species creator screen)
4. Wire to new species creation flow

Trigger date: **2026-03-31** (2 sprints from 2026-03-17).
