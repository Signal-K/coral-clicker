# Tutorial copy guardrails

## Tone

- Clear
- Short
- Mechanical
- Game-first

## Must communicate

- What the player does next
- Why that action matters for winning
- Which UI element they should touch

## Must avoid

- Mentioning Supabase, syncing, or backend systems
- Framing the game as homework or civic duty
- Over-explaining reef science before the player can act
- Long modal paragraphs

## Working copy shape

- One action per step
- Prefer verbs: `Pick`, `Feed`, `End Turn`, `Compare`, `Win`
- Only explain a resource when the player is about to spend it
