# Add specs to each organism species

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Each fish & coral should have weaknesses, strengths, and other properties. In the game, if you breed a fish, the resulting species should either aid or harm the growth of the coral species in the level environment. Breeding different fish species should produce new fish, with random chances (like in games like Gizmonauts or Dragonvale). Some fish & coral would like high-salt environments, or warmer ocean temperatures, etc. Please use real information (from the internet) for determining the properties & behaviour of the coral species that are in the game.
