# Set up starting sprites

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
We need 5 fish species and quite a few coral species - Antipathes atlantica, Antipathes furcata, Bebryce Sp., Ellisellidae, Madracis Sp., Madrepora Sp., Muricea pendula, Acanthogorgiidae, Stichopathes, Swiftia exserta, Thesea nivea, Sponge. Figure out what fish species work best with those corals (i.e. based on the locations those corals appear, what types of fish would be there? Then create sprites & spritesheet animations for all of these using the generator. Make sure to search for images of these organisms so you have some idea of what they look like
