# Scraper to pull images from Click-A-Coral Zooniverse

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Coral images are available at this link: https://www.zooniverse.org/projects/jordan-pierce/click-a-coral/collections. Interacting with the browser, you'd click on a collection and then an entry in the collection, and then save the image. Create a new directory in the godot project to store all coral anomalies, and then create a fetch/scrape function to get entries from all the collections (the image/filename should be the subject id/name).
