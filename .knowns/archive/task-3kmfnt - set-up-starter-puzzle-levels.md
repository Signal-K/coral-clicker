# Set up starter puzzle levels

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The flow of the game is basically this: users have to breed certain fish to grow different coral species, different fish increasing in population will aid or harm different coral species. Generate 10 levels; users start with different "fishfood" and will get rewards for finishing levels that they can carry over to other levels (and later use in a sandbox level).
